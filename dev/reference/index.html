Model parameters

adap is the only variable exported from MKtest module. It is a Mutable structure contaning the variables required to solve the analytical approach. Any value can be easly changed. Remember adap should be change before the execution, in other case, $\alpha_{(x)}$ will be solve with the default values. To change all the values at once, you can use MKtest.parameters in order to set specific models in a new variable.

MKtest.parameters — Type

Mutable structure containing the variables required to solve the analytical approach. All the functions are solve using the internal values of the structure. You should declare a mutable structure to the perform the analytical estimations.

MKtest.analytical_alpha — Function
analytical_alpha(param)

Analytical α(x) estimation. Solve α(x) generally. We used the expected fixation rates and SFSto approach the asympotic value accouting for background selection, weakly and strong positive selection. α(x) can be estimated taking into account the role of positive selected alleles or not. In this way we explore the role of linkage to deleterious alleles in the coding region.

\[\mathbb{E}[\alpha_{x}] = 1 - \left(\frac{\mathbb{E}[D_{s}]}{\mathbb{E}[D_{N}]}\frac{\mathbb{E}[P_{N}]}{\mathbb{E}[P_{S}]}\right)\]

Arguments

  • param::parameters

Returns

  • Tuple{Vector{Float64},Vector{Float64}}: α(x) accounting for weak adaptation, α(x) non-accouting for weak adaptation.

MKtest.set_θ! — Function
set_θ!(param)

Find the mutation rate θ_flanking such that Br(param, θ_flanking) == param.B.

Br(θ) = exp(-2·θ·Lf / (Lf·ρ - gam_flanking)) inverts analytically:

θ_flanking = -log(B) · (Lf·ρ - gam_flanking) / (2·Lf)

The closed form gives the same value as the previous root search (Roots.find_zero) to float precision, without allocations, which makes rates() faster.

Returns

  • mutates param.θ_flanking.

MKtest.Φ — Function
Φ(param,s)

Reduction in fixation probabilty due to background selection and linkage. The formulas used have been subjected to several theoretical works (Charlesworth B., 1994, Hudson et al., 1995, Nordborg et al. 1995, Barton NH., 1995).

The fixation probabilty of selected alleles are reduce by a factor $\phi$:

\[\phi(t,s) = e^{[\frac{-2\mu}{t(1+\frac{rL}{t}+\frac{2s}{t})}]}\]

Multiplying across all deleterious linkes sites, we find:

\[\Phi = \prod_{1}^{L} = \phi(t,s) = e^{\frac{-2t\mu(\psi[1,\frac{r+2s+L}{r}] - \psi[1,\frac{r(L+1)+2s+t}{r}])}{r^2}}\]

\[\phi(t,s) = e^{\frac{-2t\mu(\psi[1,\frac{r+2s+L}{r}] - \psi[1,\frac{r(L+1)+2s+t}{r}])}{r^2}}\]

Arguments

  • param::parameters: mutable structure containing the variables required to solve the model
  • gamma::Int64: selection coefficient.

The expression is Uricchio et al. 2019 Supplementary eqn. 14 / Murga-Moreno et al. 2024 (G3) eqn. 9. Previous versions omitted the factor of two on the beneficial coefficient (and the r + in the first polygamma), which made the reduction of strongly beneficial fixations about twice too large.

Returns

  • Float64: expected rate of positive fixations under background selection.

MKtest.rates — Function
rates(param; iterations, output_file, ...)

Solve iterations random models across B_bins and write the ABC reference table: models, neutral and selected cumulative SFS at each DAC, and fixation rates. Forward model: Φ from eq. 9 of the paper, beneficial SFS scaled by B with the sojourn at γ·B, and ppos solved to tolerance (models that cannot be solved are dropped).

Arguments

  • param::parameters: mutable structure containing the model (N, n, dac, shape).
  • iterations::Int64: number of prior draws; each is solved in every B bin.
  • output_file::String: rates file to write (JLD2; appends a block under N/n/cutoff).
  • gH, gL: ranges of strong / weak beneficial 2N·s (defaults [100, 1000], [1, 10]; drawn as floor(Uniform), so gL reaches 9, not 10).
  • gam_flanking, gam_dfe: ranges of flanking / coding deleterious 2N·s (paper Table 2 defaults [-1000, -500], [-1000, -200]).
  • alpha::Vector{Float64}: range of al_tot (paper default [0.1, 0.9]).
  • rho: nothing (default) holds param.ρ; a scalar holds that value; [lo, hi] draws ρ ~ Uniform(lo, hi) per model. Recorded in the rho column.
  • B_bins: background-selection bins (default 0.1:0.025:0.975 plus 0.999).

The DFE shape is drawn from Uniform(shape·2^-2, shape·2^2) (uniform, not log-uniform as in the paper). The number of dropped models is logged.

Returns

  • Dict with :models, :neut, :sel, :dsdn, :dac; the same is written to output_file.

MKtest.parse_sfs — Function
parse_sfs(data; sample_size, cutoff, gene_list, mode, sfs_columns, div_columns, l_columns, ploidy)

Function to parse polymorphism and divergence by subset of genes. The input data is based on supplementary material described at Uricchio et al. 2019. Please be sure the file is tabulated.

GeneIdPnDAF seppareted by commasPsDAF separated by commasDnDs
XXXX0,0,0,0,0,0,0,0,00,0,0,0,0,0,0,0,000
XXXX0,0,0,0,0,0,0,0,00,0,0,0,0,0,0,0,000
XXXX0,0,0,0,0,0,0,0,00,0,0,0,0,0,0,0,000

Arguments

  • data: path to the tab-separated polymorphism and divergence table, or a DataFrame.
  • sample_size::Int64: number of sampled individuals; the SFS has sample_size * ploidy - 1 bins.
  • cutoff::Vector{Float64}: frequency range to filter the SFS. Default [0.0, 1.0].
  • gene_list::Union{Nothing,Vector{S},S}: path to gene list file or vector of gene IDs. Default nothing. File formats: one gene per line (e.g. test_case.txt, controlled by mode); or multiple genes per row space-separated (e.g. test_control.txt, auto-detected – always returns one SFS per row).
  • mode::Symbol: controls output when gene_list has one gene per line. Default :case.
    • :case – single merged SFS for all listed genes.
    • :gene – one SFS per gene plus an aggregated total as the last element.
  • sfs_columns::Vector{Int64}: column numbers for Pn and Ps frequencies. Default [3, 5].
  • div_columns::Vector{Int64}: column numbers for Dn and Ds counts. Default [6, 7].
  • l_columns::Vector{Int64}: column numbers for Ln and Ls site counts. Default [8, 9].
  • ploidy::Int: chromosomes per individual. Default 2; 1 for isolines or haploids.

Returns

Three values, in this order:

  • Matrix{Float64}: Site Frequency Spectrum (non-cumulative), [dac, pn, ps]. Filtering by cutoff trims rows WITHOUT renumbering, so column 1 stays the true derived allele count.
  • Vector{Float64}: [Dn, Ds, Ln, Ls] divergence counts and site counts.
  • Matrix{Float64}: [dac, frequency, alpha_x] estimated from the cumulative SFS, so alpha(x) keeps the frequencies it was computed at even when cutoff trims the SFS.

With a multi-set gene_list, or mode = :gene, each of the three is a Vector of the above. summary_statistics and abcmk take either form.

MKtest.asymptotic_mk — Function
asymptotic_mk(sfs, divergence; model, cutoff, cumulative, na_rm, n)
asymptotic_mk(α_table; model, cutoff, na_rm)
asymptotic_mk(α_x; model, f, cutoff, na_rm)
asymptotic_mk(sfs::Vector, divergence::Vector; ...)

Asymptotic MK test (Messer & Petrov 2013): fit a curve to alpha(x) against the derived allele frequency and take its value at x = 1.

alpha(x) is computed from sfs/divergence, taken from the [dac, frequency, alpha_x] table returned by parse_sfs or α_x, or given as a vector. The Vector forms run per gene or set in parallel and return a DataFrame with one row each.

Arguments

  • model::AbstractAsymptoticModel: ExponentialFit() (default) or LinearFit(). Only this model is fitted; a fit that fails returns NaN.
  • cutoff::Vector{Float64}: frequency window [low, high]. Default [0.0, 1.0]. With sfs/divergence the SFS is cut before the cumulative sum; with a table or vector the alpha(x) values already computed are filtered. These differ under cumulative = true, so pass the cutoff where alpha(x) is computed.
  • cumulative::Bool: use the cumulative SFS (sfs/divergence only). Default true.
  • n::Union{Nothing,Int}: haploid sample size (sfs/divergence only). Needed when the SFS was trimmed by a cutoff; see α_x.
  • f: frequencies of the alpha(x) vector (vector form only). Default (1:length(α_x)) / (length(α_x) + 1), i.e. a full spectrum.
  • na_rm::Bool: drop NaN, Inf and 1.0 alpha(x) values before fitting. Default true.

Returns

  • NamedTuple: (asymptotic_mk, ci_low, ci_high, a, b, c, model, f, alpha_x). The 95% CI is the interval of the asymptote. All NaN (except model, f, alpha_x) when fewer than three values remain or the fit fails. c = 0 for LinearFit.
  • DataFrame with one such row per gene or set for the Vector forms.
source

  • n::Union{Nothing,Int}: haploid sample size behind plain vectors (default: longest curve + 1), or of a trimmed SFS (sfs/divergence only).

  • output_path: save the figure; the format comes from the extension (.png, .svg, .pdf, .ps, .html). Default nothing.
  • sample_size::Union{Nothing,Int}: project the SFS first (sfs/divergence only).
  • cumulative::Bool: use the cumulative SFS (sfs/divergence only). Default true.
  • Other keywords (xlim, ylim, size, title, ...) are passed to Plots.plot.
