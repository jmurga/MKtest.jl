Input data

The gene table

Every method starts from a tab-separated table with one row per gene and no header:

columncontent
1gene ID
2Pn, the number of nonsynonymous polymorphisms
3their derived allele frequencies, comma separated: ,0.0008,0.0015,
4Ps, the number of synonymous polymorphisms
5their derived allele frequencies
6Dn, nonsynonymous substitutions
7Ds, synonymous substitutions
8Ln, nonsynonymous sites (optional)
9Ls, synonymous sites (optional)

Frequencies must sit on the grid i / (sample_size * ploidy). Without columns 8 and 9 the site counts are set to 0: alpha is unaffected, but every omega (substitution rate per site) is NaN and dfe_ml cannot be used.

Parsing: parse_sfs

sfs, div, alpha_x = MKtest.parse_sfs("data/MKdata_tgp_may2023.txt"; sample_size = 661)

returns three values:

  • sfs: the raw SFS, a 1321 x 3 matrix [DAC Pn Ps] ([1.0 36460.0 20983.0; 2.0 20124.0 13555.0; ...]);
  • div: [Dn, Ds, Ln, Ls] = [35903.0, 45088.0, 2.19154122e7, 7.8090133e6];
  • alpha_x: [DAC frequency alpha(x)], the MK alpha above each frequency.

Inbred lines are read with ploidy = 1:

zs, zd, _ = MKtest.parse_sfs("data/dgn_zi.txt"; sample_size = 154, ploidy = 1)
# zs is 153 x 3; zd = [297477.0, 249994.0, 0.0, 0.0] (the file has no site counts)

Gene sets

gene_list selects genes: a Vector of IDs, or a file (plain or .gz).

gene_listmoderesult
none:case (default)one SFS for the whole table
none:geneone SFS per gene, plus the total as the last element
one ID per line:caseone SFS for the listed genes
one ID per line:geneone SFS per listed gene, plus their total
several IDs per line (set_1 G1 G2 ...)detected automaticallyone SFS per line
case_sfs, case_div, _ = MKtest.parse_sfs("data/MKdata_tgp_may2023.txt"; sample_size = 661,
                                         gene_list = "data/DNAonly_VIPs.txt.gz")
# case_div = [2176.0, 3112.0, 1.5620831e6, 567018.4]

ctl_sfs, ctl_div, _ = MKtest.parse_sfs("data/MKdata_tgp_may2023.txt"; sample_size = 661,
                                       gene_list = "data/DNAonly_nonVIPs.txt.gz")
# ctl_sfs is a Vector of 1000 SFS, one per control set

IDs that are not in the table are skipped silently.

Frequency cutoff

cutoff = [lo, hi] keeps the frequencies in that range (both ends included). The SFS rows are trimmed, but column 1 keeps the true DAC. A trimmed SFS cannot be projected or given to dfe_ml, which need every bin; MK tests take their own cutoff instead.

Projection and folding

s20 = MKtest.project(sfs, 20)   # 20 individuals: a 39 x 3 SFS, [1.0 14838.0 12561.0; ...]
MKtest.fold(s20)                # 20 x 3, the minor allele spectrum

project resamples the SFS to a smaller sample (hypergeometric, as dadi and moments do); counts are truncated to integers. It needs the full, untrimmed SFS. Both accept a Vector of SFS.

Other helpers: cumulative_sfs (tail sums, the input of the alpha(x) curves), reduce_sfs(sfs, bins) (the counts summed within bins equal-width frequency bins, each row at its upper edge k / bins) and bootstrap_data (Poisson resamples of one SFS).
