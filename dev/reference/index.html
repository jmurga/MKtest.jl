MKtest.parse_sfs — Function
parse_sfs(data; sample_size, cutoff = [0.0, 1.0], gene_list = nothing, mode = :case,
          sfs_columns = [3, 5], div_columns = [6, 7], l_columns = [8, 9], ploidy = 2)

Read a gene table into a raw SFS, the divergence counts and the alpha(x) table.

data is a tab-separated table with one row per gene and no header (Uricchio et al. 2019, https://doi.org/10.1038/s41559-019-0890-6), or the same table as a DataFrame:

columncontent
1gene ID
2Pn
3derived allele frequencies of the nonsynonymous polymorphisms, ,0.0008,0.0015,
4Ps
5derived allele frequencies of the synonymous polymorphisms
6, 7Dn, Ds
8, 9Ln, Ls, the nonsynonymous and synonymous site counts (optional)

Frequencies are rounded to 4 digits (3 when sample_size * ploidy < 100) and matched to the grid i / (sample_size * ploidy); zeros are ignored. A frequency off the grid throws a DimensionMismatch, except with a multi-set gene_list, where it is skipped. Without the site-count columns, Ln and Ls are 0.

Keywords

  • sample_size::Int64: number of sampled individuals; the full SFS has sample_size * ploidy - 1 rows.
  • ploidy::Int: chromosomes per individual, 1 for inbred lines or haploids.
  • cutoff::Vector{Float64}: frequency range [lo, hi] kept, both ends included. Rows are removed without renumbering, so column 1 stays the true DAC. A trimmed SFS cannot be given to project or dfe_ml.
  • gene_list: a Vector of gene IDs, or the path of a file (plain or .gz) with one ID per line, or several space-separated IDs per line (one set per line, detected automatically). IDs absent from the table are skipped silently.
  • mode::Symbol: :case (one SFS for all selected genes) or :gene (one SFS per gene plus their total as the last element). Ignored for a multi-set file; any other value acts as :case.
  • sfs_columns, div_columns, l_columns: column numbers of the Pn and Ps frequencies, of Dn and Ds, and of Ln and Ls.

Returns

Three values, in this order:

  • sfs::Matrix{Float64}: the raw (non-cumulative) SFS [DAC Pn Ps].
  • divergence::Vector{Float64}: [Dn, Ds, Ln, Ls].
  • alpha_x::Matrix{Float64}: [DAC frequency alpha(x)], alpha(x) from the tail sums of the (cut) SFS, 1 - (Ds / Dn) Pn(>= x) / Ps(>= x), rounded to 5 digits.

With a multi-set gene_list or mode = :gene, each of the three is a Vector with one element per set or gene (plus the total for :gene).

MKtest.project — Function
project(sfs, n)

Project an SFS down to n diploid individuals (2n chromosomes), by hypergeometric sampling as in dadi and moments.

The projected counts are truncated to integers. Only columns 2 and 3 are projected, and the input is taken to be a full spectrum of size(sfs, 1) + 1 chromosomes: an SFS trimmed by parse_sfs(...; cutoff) gives a wrong projection. For data read with ploidy = 1, n still means 2n chromosomes.

Arguments

  • sfs::Matrix{Float64} (or a Vector of them, projected in parallel threads): the full raw SFS [DAC Pn Ps] from parse_sfs.
  • n::Int64: number of diploid individuals to project to. Throws an AssertionError unless n < size(sfs, 1).

Returns

  • Matrix{Float64} [DAC Pn Ps] with 2n - 1 rows (a Vector of them for a Vector input).

MKtest.cumulative_sfs — Function
cumulative_sfs(sfs, freqs = true)

Tail sums of an SFS: row i holds the counts of rows i, i+1, ..., end, so Pn(x) and Ps(x) become the numbers of polymorphisms at frequency >= x.

The original asymptotic MK test uses the counts at x itself; the tail sums have the same asymptote and are less sensitive to the sample size. A row whose tail sum (over all count columns) is not positive is set to 0.

Arguments

  • sfs::Union{Array,SubArray}: an SFS matrix, [DAC Pn Ps] from parse_sfs.
  • freqs::Bool: column 1 holds the DAC (or frequency) and is copied unchanged; false cumulates every column.

Returns

  • A matrix of the same size and element type as sfs.

MKtest.reduce_sfs — Function
reduce_sfs(sfs, bins; n = nothing)

Collapse an SFS into bins derived allele frequency bins of equal width.

Row i has frequency x = DAC / n; it goes to bin k when (k - 1) / bins < x <= k / bins, and the counts of columns 2 to end are summed within each bin. Bins that receive no row hold 0.

Arguments

  • sfs::AbstractMatrix: an SFS [DAC Pn Ps ...] (any number of count columns).
  • bins::Int: number of frequency bins.

Keywords

  • n::Union{Nothing,Int}: haploid sample size. By default size(sfs, 1) + 1, which needs the full SFS (DAC 1..n-1). Pass it for any SFS trimmed by parse_sfs(...; cutoff): a trim at the low end throws without it, but a top-only trim (DAC 1..k) cannot be told apart from a full SFS of k + 1 chromosomes and would give wrong frequencies.

Returns

  • Matrix{Float64} of bins rows: column 1 is the upper edge k / bins of each bin (a frequency, which fww_mk, imputed_mk and standard_mk accept as such), the other columns the summed counts.

Example

sfs = hcat(1:9, ones(9), 2 .* ones(9))   # n = 10 chromosomes
MKtest.reduce_sfs(sfs, 2)                # [0.5 5 10; 1.0 4 8]

MKtest.imputed_mk — Function
imputed_mk(sfs, divergence; cutoff = 0.15, n = nothing)

Imputed MK test (Murga-Moreno et al. 2022, https://doi.org/10.1093/g3journal/jkac206): the slightly deleterious nonsynonymous polymorphisms below cutoff are estimated and subtracted from Pn.

With low = frequency < cutoff and high = frequency >= cutoff, the deleterious count is Pn_low - Pn_high (Ps_low / Ps_high), set to 0 when it is negative, larger than Pn, or Ps_high = 0. Then alpha = 1 - (Pn_neutral / Ps) (Ds / Dn) (rounded to 3 digits), with a Fisher exact test of [Ps Pn_neutral; Ds Dn] (counts rounded up to integers).

Arguments

  • sfs::Matrix: raw SFS [DAC Pn Ps]; the frequency of a row is DAC / n. Column 1 may instead hold frequencies in (0, 1] (as reduce_sfs returns), used as they are.
  • divergence::Vector: [Dn, Ds, Ln, Ls]; [Dn, Ds] alone also works.

Keywords

  • cutoff::Float64: derived allele frequency separating the low-frequency class.
  • n::Union{Nothing,Int}: haploid sample size. By default size(sfs, 1) + 1, which needs the full SFS (DAC 1..n-1). Pass it for any SFS trimmed by parse_sfs(...; cutoff): a trim at the low end throws without it, but a top-only trim (DAC 1..k) cannot be told apart from a full SFS of k + 1 chromosomes and would give wrong frequencies.

Returns

  • NamedTuple (alpha, p_value, b, f, d, omega, omega_a, omega_d). b, f and d are the fractions of new nonsynonymous mutations that are slightly deleterious, neutral and strongly deleterious; omega = (Dn/Ln) / (Ds/Ls), omega_a = alpha omega, omega_d = omega - omega_a. These six are NaN without Ln and Ls (2-element divergence, or site counts of 0); everything is NaN when Ps = 0 or Dn = 0.
source

MKtest.asymptotic_mk — Function
asymptotic_mk(sfs, divergence; model = ExponentialFit(), cutoff = [0.0, 1.0],
              cumulative = true, na_rm = true, n = nothing)
asymptotic_mk(α_table; model, cutoff, na_rm)
asymptotic_mk(α_x::AbstractVector{<:Real}; model, f = nothing, cutoff, na_rm)
asymptotic_mk(sfs::Vector, divergence::Vector; kwargs...)
asymptotic_mk(α_tables::Vector{<:AbstractMatrix}; kwargs...)
asymptotic_mk(α_xs::Vector{<:AbstractVector}; kwargs...)

Asymptotic MK test (Messer & Petrov 2013): fit a curve to alpha(x) against the derived allele frequency x and take its value at x = 1.

alpha(x) is computed from a raw SFS [DAC Pn Ps] and [Dn, Ds, ...] with α_x, taken from a [DAC frequency alpha(x)] table (the third value of parse_sfs, or α_x), or given as a bare vector. The Vector forms fit every dataset in parallel threads.

Keywords

  • model::AbstractAsymptoticModel: ExponentialFit or LinearFit. Only this model is fitted, with no fallback to the other.
  • cutoff::Vector{Float64}: frequency window [lo, hi], both ends included. From an SFS, rows are cut before the tail sums; from a table or vector, the alpha(x) values already computed are filtered. The two differ under cumulative = true, so apply the cutoff where alpha(x) is computed.
  • cumulative::Bool: tail sums of the SFS (SFS form only).
  • n::Union{Nothing,Int}: haploid sample size (SFS form only); needed for an SFS trimmed by a cutoff, see α_x.
  • f: frequencies of a bare alpha(x) vector. Default (1:k) / (k + 1) for k values, i.e. a full spectrum; a length mismatch throws an ArgumentError.
  • na_rm::Bool: drop NaN, Inf and 1.0 alpha(x) values (alpha = 1 means Pn = 0) before fitting.

A table that does not have 3 columns throws an ArgumentError.

Returns

  • NamedTuple (asymptotic_mk, ci_low, ci_high, a, b, c, model, f, alpha_x): the asymptote, its 95% CI (delta method over the fit covariance, t quantile), the fitted coefficients (c = 0 for LinearFit), the model name (:exponential or :linear), and the frequencies and alpha(x) values used. The asymptote, CI and coefficients are NaN when fewer than three values remain or the fit fails.
  • Vector forms: a DataFrame with one such row per dataset, and a warning giving the number of failed fits.
source
MKtest.ExponentialFit — Type
ExponentialFit()

Fit alpha(x) = a + b exp(-c x) in asymptotic_mk (Messer & Petrov 2013); the asymptote is a + b exp(-c).

The curve is first fitted with bounds a, b ∈ [-1, 1], c ∈ [1, 10] from (-1, -1, 1), then refitted without bounds from that solution. A fit that throws or does not converge gives NaN.

MKtest.α_x — Function
α_x(sfs, divergence; cutoff = [0.0, 1.0], cumulative = true, n = nothing)

MK alpha as a function of the derived allele frequency x, alpha(x) = 1 - (Pn(x) / Ps(x)) (Ds / Dn).

The frequency of each row is DAC / n. Rows outside cutoff are removed first; with cumulative = true Pn(x) and Ps(x) are then the counts at frequency >= x (see cumulative_sfs), otherwise the counts at x alone.

Arguments

  • sfs::Matrix: raw SFS [DAC Pn Ps] from parse_sfs.
  • divergence::Vector: [Dn, Ds, ...].

Keywords

  • cutoff::Vector{Float64}: frequency window [lo, hi], both ends included.

By default size(sfs, 1) + 1, which is only right for a full spectrum: an SFS whose DAC column does not run 1, 2, ..., size(sfs, 1) throws an ArgumentError unless n is given. A trimmed upper end cannot be detected, so pass n for any SFS trimmed by parse_sfs(...; cutoff). An n not larger than the last DAC throws an ArgumentError.

Returns

  • Matrix{Float64} [DAC frequency alpha(x)], one row per frequency kept.

MKtest.grapes — Function
grapes(sfs, divergence, model; n = 0, nearly_neutral = 5, FWW_threshold = 0.15,
       nb_rand_start = 0, anc_to_rec_Ne_ratio = 1.0, no_div_data = false,
       no_div_param = false, no_syn_orient_error = false, fold = false,
       fixed_param = "")

Run the GRAPES binary (Galtier 2016) on each dataset and return its estimates.

The binary comes from the grapes-static package of the genomedk conda channel, installed through CondaPkg on first use. Each dataset is written to a temporary .dofe file and the runs go in parallel threads; the files of a successful run are removed. For a Julia implementation of the same model see dfe_ml.

Arguments

  • sfs: raw SFS [DAC Pn Ps], a Matrix or a Vector of them. It must be a full spectrum (GRAPES reads size(sfs, 1) + 1 chromosomes, or 2n after projection).
  • divergence: [Dn, Ds, Ln, Ls], a Vector or a Vector of them. Ln and Ls are required.
  • model::String: "GammaZero", "GammaExpo", "GammaGamma", "DisplGamma", "ScaledBeta", "FGMBesselK" or "all"; anything else throws an AssertionError.

Keywords (GRAPES options)

  • n::Int64: if positive, project the SFS to n diploid individuals first.
  • nearly_neutral::Int64: -nearly_neutral, the S threshold above which a mutation counts as adaptive.
  • FWW_threshold::Float64: -FWW_threshold, the lowest frequency kept in GRAPES' FWW alpha.
  • nb_rand_start::Int64: -nb_rand_start, random starting points of the optimizer.
  • anc_to_rec_Ne_ratio::Float64: -anc_to_rec_Ne_ratio, the ratio of the divergence to the polymorphism Ne.
  • no_div_data::Bool: -no_div_data, estimate the DFE from the polymorphism alone.
  • no_div_param::Bool: -no_div_param, the [-A] version of Galtier (2016); ignored for GammaZero.
  • no_syn_orient_error::Bool: -no_syn_orient_error, the same misorientation rate for synonymous and nonsynonymous sites.
  • fold::Bool: -fold, fit the folded SFS.
  • fixed_param::String: -fixed_param, the path of a GRAPES control file of parameters fixed to given values; empty for none.

A 0 anywhere in divergence (including Ln = Ls = 0 from a table without site counts) throws an ArgumentError.

Returns

  • DataFrame: the GRAPES output tables of the datasets that ran, stacked. For a single model the columns are GRAPES' first 20, those of model, and those from theta on; "all" keeps every column. A dataset that fails gives a warning and no row, so rows then no longer follow the dataset order.

MKtest.dfe_ml — Function
dfe_ml(sfs, divergence, model::AbstractDFEModel; kwargs...) -> DFEResult

Maximum-likelihood fit of the DFE model and alpha to the SFS and divergence of one or several datasets, with GRAPES' model (Galtier 2016). One fit per dataset.

Arguments

  • sfs: a matrix [DAC Pn Ps] with every bin 1..n-1 (unfolded; n chromosomes), as parse_sfs returns it, or a Vector of such matrices.
  • divergence: [Dn, Ds, Ln, Ls], or a Vector of those (one per SFS).
  • model: an AbstractDFEModel instance (GammaZero(), GammaExpo(), WithLethal(GammaZero()), a user model, ...).

Keywords (data)

  • project_sfs::Union{Nothing,Int} = nothing: project the SFS to this many diploid individuals (2 project_sfs chromosomes) with project first.
  • fold::Bool = false: fold the SFS (misorient is then not fitted).
  • labels = nothing: names of the datasets (the dataset column); default 1:N.
  • Ln_poly, Ls_poly: site counts of the polymorphism data, when they differ from the divergence ones (default: Ln, Ls).

Keywords (model axes; each is independent of the others)

  • ne_model::AbstractNeModel = ConstantNe(): AncestralNeRatio(r) or AncestralNeRatio(:free) (adds the parameter ne_ratio).
  • div_model::AbstractDivergenceModel = SaturatedDivergence(): DFEConstrainedDivergence() (GRAPES -no_div_param) or NoDivergence() (-no_div_data).
  • demography::Union{Nothing,AbstractDemography} = nothing: NuisanceRj() (GRAPES' per-bin r_j) or Equilibrium(); nothing takes default_demography(expectation).
  • dominance::AbstractDominance = Additive(): Dominance(h), DominanceFunction(f).
  • expectation::AbstractSFSExpectation = PRFSojourn().
  • integrator::AbstractIntegrator = ExactSojourn(); RombergIntegrator() is GRAPES' own rule (use it to compare with the binary).
  • quadrature::AbstractDFEQuadrature = MidpointDensity(); or IntervalCDF().
  • s_grid::Union{Nothing,AbstractSGrid} = nothing: nothing takes default_s_grid(expectation) (GrapesGrid()).
  • kernel::AbstractLikelihoodKernel = PoissonKernel(); or NegativeBinomialKernel().
  • optimizer::AbstractOptimizer = LBFGSOptimizer(); or NelderMeadOptimizer().
  • summaries = (DFEMAlpha(),): the AbstractAlphaSummary column sets of inference.

Keywords (fit)

  • fixed::NamedTuple = (;): pin parameters by name, e.g. (ben_prop = 0.0,).
  • bounds::NamedTuple = (;): replace bounds by name, e.g. (ben_prop = (1e-6, 0.99),).
  • no_syn_orient_error::Bool = false: do not fit misorient.
  • nb_rand_start::Int = 0: extra random starting points (seeded, reproducible).
  • nearly_neutral::Real = 5: S threshold of adaptive substitutions in alpha.
  • alpha_ci_threshold::Real = 1.92: log-likelihood drop of the alpha CI (half the chi-square(1) 95% quantile; GRAPES' interval). 0 disables it and the CI columns are NaN. The CI exists only under SaturatedDivergence, as in GRAPES.
  • cache::DFECache = DFECache(): precomputed tables; pass one to reuse them across calls (safe across threads).

Returns

A DFEResult: inference (alpha, omegas, lnL, convergence: one row per fit), params (every fitted parameter, long), sfs (observed and fitted SFS, r_j), divergence (expected Dn by S class), config (the settings) and extra. Parameter names follow <component>_<quantity> (del_shape, del_mean, ben_prop, ben_mean, ..., misorient); from_legacy_name maps the GRAPES / pre-2026-10-15 names.

MKtest.dfe_model_comparison — Function
dfe_model_comparison(r::DFEResult) -> (aic = DataFrame, lrt = DataFrame)
dfe_model_comparison(sfs, divergence; models, cache = DFECache(), kwargs...)
    -> (aic = DataFrame, lrt = DataFrame, result = DFEResult)

AIC (with Akaike weights) and likelihood-ratio tests between DFE models fitted to the same data under the same likelihood function: fits are grouped by dataset and by the settings that define the likelihood (expectation, integrator, quadrature, grid, dominance, demography, Ne model, divergence model, kernel, fold, projection), so models fitted with different optimizers, starts, fixed values or bounds are compared, and models fitted under different integrators are not. Model i is nested in j when its free parameters are a strict subset of j's (GammaZero in GammaExpo, ExpoZero in GammaZero, GammaZero in WithLethal(GammaZero())); non-converged fits stay in the AIC table but not in the LRTs. Both tables carry dataset and group (the likelihood setting) and are sorted by log-likelihood within a group: pick the AIC-best model with argmin(aic), not row 1.

The second form fits models (default: the eleven continuous shapes) with dfe_ml, sharing one DFECache, and forwards kwargs to it. fixed and bounds are given to each model restricted to the parameters it has, so bounds = (ben_prop = (1e-6, 0.99),) widens the beneficial class of the models that have one.

MKtest.DFEResult — Type
DFEResult

The result of dfe_ml (and of the fitting form of dfe_model_comparison). Tables, all DataFrames keyed by the integer fit with readable dataset and model columns:

  • inference: one row per fit. model, config (row of config), n (chromosomes), converged, loglik, n_params, theta, then the summary columns (DFEMAlpha(): alpha, alpha_ci, omega_a, omega_a_ci, omega_na, omega_na_ci, omega_obs, alpha_div, alpha_dfe). Intervals are (lo, hi) tuples; NaN when not computed.
  • params: one row per fitted parameter: parameter, kind ("dfe" or "nuisance"), value, lower, upper, free, at_bound (a free parameter on its bound is not an estimate). The same columns for every model, so models of any shape stack.
  • sfs: one row per SFS bin: j, pn_obs, ps_obs, pn_exp, ps_exp (fitted expectation), r_j (the per-bin nuisance, 1 under Equilibrium() and for j = 1).

ABC-MK

MKtest.parameters — Type
parameters(; N = 1000, n = 500, dac = [2, 4, 5, 10, 20, 50, 200, 500, 700], ...)

Mutable keyword struct (Parameters.@with_kw) holding the ABC-MK analytical model. Every model function (rates, analytical_alpha, sfs_neg, ...) reads these fields, and some set them. Set N, n, dac and cutoff to match the data; most of the others are drawn from the priors by rates.

All selection coefficients (γ_weak, γ_strong, γ_deleterious, γ_flanking) are 2N times the heterozygote selection coefficient. θ_* and ρ are population-scaled per site (4Nμ, 4Nr).

MKtest.rates — Function
rates(param; iterations, output_file, γ_strong = [100, 1000], γ_weak = [1, 10],
      γ_flanking = [-1000, -500], γ_deleterious = [-1000, -200], α = [0.1, 0.9],
      ρ = nothing, B_bins = vcat(0.1:0.025:0.975, 0.999), weak = true)

Build the ABC-MK reference table: draw iterations models from the priors, solve each in every B bin, and append the table to the JLD2 file output_file.

For each draw, set_ppos! solves the beneficial probabilities at B = 0.999; draws it cannot solve are dropped (the count is logged). Then, for each B, the model's expected synonymous and nonsynonymous SFS tails (DAC >= k) at every param.dac and its fixation rates are computed. The draws run on all Julia threads (julia -t auto); with a seed, the table reproduces only at the same thread count.

Arguments

  • param::parameters: the model; N, n, dac, cutoff and shape are used as set, the other drawn fields are overwritten in per-task copies.

Keywords

  • iterations::Int64: number of prior draws; the table has up to iterations * length(B_bins) rows.
  • output_file::String: JLD2 file, opened in append mode; the block is written under the group "N/n/cutoff=[lo,hi]", which must not exist yet.
  • γ_strong, γ_weak::Vector{Int64}: ranges of the strongly and weakly beneficial coefficients, drawn as floor(Uniform(lo, hi)) (so γ_weak reaches 9, not 10).
  • γ_flanking, γ_deleterious::Vector{Int64}: ranges of the flanking and coding deleterious coefficients (mean of the DFE), drawn the same way.
  • α::Vector{Float64}: range of param.α, drawn uniformly and rounded to 2 digits.
  • ρ: nothing keeps param.ρ; a positive number fixes ρ; [lo, hi] draws ρ ~ Uniform(lo, hi) per model. A fixed ρ draws no random numbers.
  • B_bins::Vector{Float64}: background selection values (37 by default).

  • basesize, distributed: not used.

The DFE shape is drawn from Uniform(shape/4, 4 shape). All coefficients are 2N times the heterozygote selection coefficient.

Returns

A Dict with the same content as the file block:

  • :models: DataFrame, one row per (draw, B). Its columns keep their stored names, so earlier tables stay readable: B (B x 1000), al_low (α_weak), al_tot (α), gam_flanking (γ_flanking), gL (γ_weak), gH (γ_strong), shape, gam_dfe (γ_deleterious), rho (ρ), ne_ratio (always 1).
  • :neut, :sel: OrderedDict{Int,Array} from each DAC to the expected synonymous and nonsynonymous tails of every row.
  • :dsdn: matrix of fixation rates, columns Ds, Dn, and the parts of Dn from weakly and from strongly beneficial mutations.

The file block also stores options, a description of the forward model.

MKtest.RjSampling — Type
RjSampling(; w = (0.0, 2.5), anchor = (0.15, 0.70), tilt = 0.05)

IndependentSampling with a demographic nuisance on the polymorphism: the data's synonymous SFS distortion r_i (GRAPES' r_j), normalised on an anchor band, is applied to the model's synonymous class and, raised to a random power w, to its nonsynonymous class. With tilt > 0 the nonsynonymous class also gets a random frequency tilt. Fixations are drawn as in IndependentSampling.

The default sampler of summary_statistics and abcmk, used there with FlatAlphaPrior and stat = "median".

Keywords

  • w = (0.0, 2.5): range of w ~ Uniform(w...), drawn per table row. w = 0: nonsynonymous sites ignore the distortion; w = 1: the same distortion on both classes (GRAPES); w > 1: stronger on nonsynonymous sites. Needs 0 <= w[1] <= w[2].
  • anchor = (0.15, 0.70): band of derived-allele frequency on which r is normalised, so that r changes the shape of the spectra but never the Pn/Ps level, which only α sets. Needs 0 < anchor[1] < anchor[2] <= 1.
  • tilt = 0.05: range of τ ~ Uniform(-tilt, tilt); 0 draws no τ.

Steps, per dataset and table row

  1. The DACs of param.dac split the spectrum into intervals [dac_i, dac_(i+1) - 1], the last one up to nn - 1. The row's interval masses e_s,i, e_n,i are differences of its tails.
  2. r_i = (Ps_obs,i / sum Ps_obs) / (e_s,i / sum e_s), divided by its e_s-weighted mean over the intervals lying wholly inside the anchor band (anchor[1] <= dac_i/nn and stop_i/nn <= anchor[2]).
  3. The synonymous masses become e_s,i r_i and the nonsynonymous masses e_n,i r_i^w.
  4. If tilt > 0, the nonsynonymous masses are also multiplied by f_i^τ / c_τ, with f_i = sqrt(dac_i stop_i) / nn and c_τ chosen so the Pn mass on the anchor band is unchanged: a zero-mean change of shape aimed at expansions.
  5. ps_k and pn_k are drawn from the distorted tails as in IndependentSampling.

w and τ are marginalised: they are not written to the summaries.

Requirements

param.dac ascending, Ps > 0 in every DAC interval of each dataset, and at least one whole interval inside the anchor band (at n = 50, DACs 20 and 50 give the interval 20-49). Each violation throws an ArgumentError; valid_data finds the datasets that would fail. Pass the RAW per-frequency SFS: summary_statistics builds the tails.

The defaults were selected on SLiM simulations (two-epoch histories at n = 50 and the Tennessen history at n = 661), where they gave an α RMSE of 0.029 and 0.030 against 0.055 and 0.039 for the v1.0.0 sampler and prior.

MKtest.IndependentSampling — Type
IndependentSampling()

Poisson sampler of ABC-MK v1.0.0: every class is drawn as an independent Poisson whose mean is the model's share of the observed total.

Let O_k be the observed polymorphism at DAC >= k (Pn + Ps) and D = Dn + Ds the observed divergence. For a table row with tail rates λps_k, λpn_k and fixation rates λds, λdn, λW, λS:

ps_k ~ Poisson(λps_k / (λps_k + λpn_k) O_k)    pn_k ~ Poisson(λpn_k / (λps_k + λpn_k) O_k)
ds   ~ Poisson(λds / (λds + λdn) D)            dn   ~ Poisson(λdn / (λds + λdn) D)
sw   ~ Poisson(λW / (λds + λdn) D)             ss   ~ Poisson(λS / (λds + λdn) D)

sw + ss > dn can happen, so a sampled α above 1 is kept as a sampling artifact; only non-finite rows are dropped. Pass it as sampling to summary_statistics or abcmk.

MKtest.FlatAlphaPrior — Type
FlatAlphaPrior(; bin = 0.01, floor = 0.001, by_B = true)

Default row prior of summary_statistics and abcmk: table rows drawn with replacement, weighted so that the prior on each row's realised α, (λW + λS) / λdn, is flat within each B value of the table.

A row's weight is π_B / max(n_bin, floor * n_B), where n_bin counts the rows of its α bin (width bin) at its B, n_B the rows at that B, and π_B = n_B / (rows * occupied α bins at B). Every α bin of a B value then carries the same weight and every B keeps its share of rows. floor stops the sparse edges of the α range from taking huge weights. With by_B = false, α is flattened over the whole table (weight 1 / max(n_bin, floor * rows)), which also moves prior mass toward high B. Rows with a non-finite α get weight 0.

Why: a table drawn with uniform α labels has a realised-α prior that falls with α, because the realised α shrinks with B; rejection ABC then pulls α toward 0 wherever the likelihood is broad.

Throws an ArgumentError unless bin > 0 and 0 <= floor < 1.

MKtest.abc_loclinear — Function
abc_loclinear(target_file, param_summaries_file; P, tol, transformation = "none",
              kernel = "epanechnikov") -> (accepted, adjusted)

Rejection and local-linear regression ABC for one dataset, a port of abc(..., method = "loclinear") from the R package abc.

target_file holds the observed summary statistics (one row) and param_summaries_file the table, P parameter columns followed by the summary statistics, as written by summary_statistics.

  1. Each statistic is scaled by its median absolute deviation over the table, and the tol rows closest to the target in Euclidean distance are accepted.
  2. Accepted rows are weighted by kernel with bandwidth the largest accepted distance: "epanechnikov" (default), "gaussian", "rectangular", "triangular", "biweight" or "cosine" (lower case).
  3. The parameters are transformed: "none", "log" (zeros replaced by the smallest non-zero value; throws an ArgumentError if any accepted value is negative, e.g. a negative ωₙₐ) or "tan" (the tangent transformation of Hamilton et al. 2005, bounded by the table's range).
  4. A weighted linear regression of each parameter on the statistics corrects the accepted values toward the target; a second regression of the log squared residuals rescales them (heteroscedastic correction).
  5. Both sets are back-transformed.

Keywords

  • P::Int64: number of parameter columns.
  • tol::Int64: number of accepted rows.
  • transformation::String = "none", kernel::String = "epanechnikov": as above.

Returns

(accepted, adjusted): two tol x P matrices, the rejection sample and the regression-adjusted posterior.

MKtest.abcreg_loclinear — Function
abcreg_loclinear(target, param, sumstat; tol, transformation = "none") -> Matrix{Float64}

ABCreg (Thornton 2009) on one dataset, in Julia and in memory: the algorithm of the binary that ABCreg runs, transcribed from its source (reg.cc, generate_posterior.cc, abc_algebra.cc, transformations.cc). Cite ABCreg when you use it.

param holds the table's parameter columns and sumstat its summary statistics, one row per table row; target is the observed summary row.

  1. Each statistic is centred and divided by its sample standard deviation over the table (the target with the same values).
  2. The acceptance radius q is the tol / nrow quantile of the Euclidean distances (GSL's interpolated quantile), and rows with distance strictly below q are accepted. If q is 0, the exact matches are returned without regression, as ABCreg does.
  3. Epanechnikov weights 1 - d^2 / q^2.
  4. Each parameter (transformed with the binary's -L, log(x + 1e-4), or -T, the tangent transformation over the table's range, when transformation is "log" or "tan") is regressed on the scaled statistics by weighted least squares through GSL's balanced SVD with tolerance 1 / n_accepted.
  5. Adjusted value = prediction at the target + the row's residual, back-transformed. No heteroscedastic correction (unlike abc_loclinear).

Under "log" a parameter at or below -1e-4 (a negative ωₙₐ) makes the binary abort; here that parameter's column is NaN and the other columns are unaffected.

Agrees with the binary to its printed precision (6 significant digits); the parity test is test/abc_in_memory.jl.

Returns

The adjusted posterior, one row per accepted table row in table order; zero rows if none was accepted.

set_ppos!(param; warm_start = [0.0, 0.0], atol = 1e-6)

set_θ!(param) -> Float64

Set param.θ_flanking to the flanking mutation rate that gives the background selection value param.B, and return it.

MKtest.Φ — Function
Φ(param, s::Int64) -> Float64

Factor (in (0, 1]) by which background selection and linkage reduce the fixation probability of a beneficial mutation with coefficient s (2N times the heterozygote coefficient), from the param.L_flanking linked deleterious sites (Charlesworth 1994, Barton 1995).

The product over linked sites of the per-site reduction gives

\[\Phi = e^{-\frac{2 t \mu \left(\psi_1\left(\frac{r + 2s + t}{r}\right) - \psi_1\left(\frac{r (L_f + 1) + 2s + t}{r}\right)\right)}{r^2}}\]

with t = |γ_flanking|/NN, μ = θ_flanking/(2NN), r = ρ/(2NN), s = s/NN and ψ₁ the trigamma function: Uricchio et al. 2019, Supplementary eq. 14, and Murga-Moreno et al. 2024, eq. 9.

Binomial sampling matrix that projects population frequencies onto the sample.

MKtest.fix_neg — Function
fix_neg(param, ppos::Float64) -> Float64

Expected rate of deleterious nonsynonymous fixations per new coding mutation, integrated over the gamma DFE (param.shape, param.scale) at Ne = B N:

\[\mathbb{E}[D_{n-}] = (1 - p_{syn})(1 - p_{+})\, 2^{-a} B^{-a} b^{a} \left(\zeta\left(a, \tfrac{1}{2}\left(2 - \tfrac{1}{N B} + \tfrac{b}{B}\right)\right) - \zeta\left(a, 1 + \tfrac{b}{2B}\right)\right)\]

with a the shape, b the scale, ζ the Hurwitz zeta function and p₊ = ppos the probability that a nonsynonymous mutation is beneficial (callers pass 0.5 p_weak + 0.5 p_strong).

p_fix(param, gam::Int64) -> Float64

Fixation probability of a new beneficial mutation with coefficient gam (2N times the heterozygote coefficient, s = gam/NN):

\[p_{fix} = \frac{1 - e^{-2s}}{1 - e^{-2\gamma}}\]

For s >= 0.1 it uses instead the survival probability of a branching process with Poisson(1 + s) offspring (200 fixed-point iterations), following Uricchio et al. 2014. Background selection is not included: see fix_pos_sim.

bootstrap_parameters(; data, annotations, distance, max_reps, tolerance, iterations,
                     confounding_factors, output, filter_hla_hist, seed)

Settings of bootstrap, the matched control-set builder of Enard & Petrov (2020) and Di et al. (2021). A keyword (Parameters.@with_kw) mutable struct; every field has a default.

Fields

  • data::String: file with the case gene IDs, one per line, no header. Default "ensembl_list.txt".
  • annotations::String: tab-separated BED file without header, at least four columns (chromosome, start, end, gene ID). The gene IDs in column 4 define the gene universe. Default "ensembl_gene_coords_v109.bed".
  • distance::Int64: minimum distance in bp between the midpoint of a candidate control gene and the midpoint of the closest case gene (see get_distance). Genes on a chromosome without case genes are always far enough. Default 1, which only excludes genes sharing a midpoint with a case gene.

  • confounding_factors::String: file without header, separated by spaces or tabs: gene ID then one numeric column per factor. Default "confounding_factors.txt".
  • output::String: output prefix, without extension; bootstrap writes <output>_case.txt and <output>_control.txt. Default "test".
  • filter_hla_hist::Bool: remove the human HLA and histone genes (Ensembl gene IDs, lists hla_genes and hist_genes in src/bootstrap.jl) from case and controls. Default true.
  • seed::Union{Nothing,Int}: seed of the draws; iteration i uses Xoshiro(seed + i), so the sets do not depend on the thread count. nothing (default) draws from the global RNG.

MKtest.bootstrap — Function
bootstrap(param::bootstrap_parameters)

Build matched control sets for a case gene list and write them to disk (Enard & Petrov 2020; Di et al. 2021). See bootstrap_parameters for the settings.

Steps: read the case IDs (data), the confounding factors and the annotations gene IDs; compute the distance of every gene to the closest case gene with get_distance; keep as candidate controls the genes present in annotations and in the factor file, at least distance bp from every case gene and not in the case set; keep only case genes present in both files; drop HLA and histone genes if filter_hla_hist. Then run iterations independent matched draws (get_bootstrap) in parallel threads, each cut into 100 control sets of length(case) genes, for iterations * 100 sets in total.

Warns when there are fewer than 1.5 candidate controls per case gene. Throws an ErrorException, and writes nothing, when an iteration cannot reach its target.

Files written

  • <output>_control.txt: one control set per line, sample_i GENE GENE ... (space-separated, i = 1 ... 100 * iterations); the format parse_sfs reads as gene_list. An existing file is replaced.
  • <output>_case.txt: the case genes kept after the filters, one per line.

Returns

  • (case = Vector{String}, control = Vector{String}): the case genes kept and the lines of <output>_control.txt.

get_distance(data, annotation) -> DataFrame

Distance in bp from every gene of annotation to the closest case gene listed in data.

MKtest.get_bootstrap — Function
get_bootstrap(case_set, control_set; factors, max_reps, tolerance, rng) -> Vector{String}

Draw one pool of matched control genes for case_set from control_set (Enard & Petrov 2020).

Pairs of distinct candidate genes are drawn at random and accepted when the running average of every confounding factor stays within tolerance * |case average| of the case average and neither gene exceeds a share of max_reps / length(case_set) of the pool. The running average starts from a seed of 100 pseudo-genes at the case average; each accepted pair removes one of them. Drawing stops at 100 + 110 * length(case_set) genes, the pool bootstrap cuts into 100 sets (the first genes are burn-in).

Arguments

  • case_set::Vector{String}, control_set::Vector{String}: gene IDs; every one must be a key of factors.
  • factors::Dict{String,Vector{Float64}}: confounding factors of each gene.
  • max_reps::Int64, tolerance::Float64: as in bootstrap_parameters.
  • rng::AbstractRNG: random number generator. Default Random.default_rng().

Returns

  • The accepted control genes in order of acceptance (with repeats), or an empty Vector{String} if 5 million draws in a row were rejected before reaching the target.

Balancing selection

MKtest.α_b — Function
α_b(r_s::Vector{Int64}) -> DataFrame
α_b(r_s::Vector) -> DataFrame

Proportion of shared non-synonymous polymorphisms maintained by balancing selection, αᵦ, from the test of Soni, Vos & Eyre-Walker (2022) (cited as "Vivak et al. (2022)" in earlier versions of this package).

r_s = [rₙ, rₛ, sₙ, sₛ] are the private (r) and shared (s) non-synonymous and synonymous polymorphism counts, as returned by parse_private_share. Z = (sₙ / sₛ) / (rₙ / rₛ) (0 if sₛ, rₙ or rₛ is 0) and αᵦ = 1 - 1 / Z if Z > 1, else 0. The interval comes from 1000 multinomial resamples of the sum(r_s) SNPs over the four classes (unseeded; a resample missing a class gives Z = 0): the 2.5% and 97.5% quantiles of the resampled Z, a 95% percentile interval, mapped to α the same way.

The second method applies the first to each element of a vector of count vectors (in parallel, logs suppressed) and stacks the rows.

Returns

  • DataFrame, one row per count vector: Z, αᵦ, α_low and α_high (the 95% bootstrap interval of Z mapped to α), pnᵦ = αᵦ * sₙ (the number of shared non-synonymous SNPs under balancing selection), the input counts rₙ, rₛ, sₙ, sₛ, and variance (the variance of the bootstrap Z).
