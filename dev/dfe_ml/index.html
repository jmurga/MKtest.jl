DFE and alpha by maximum likelihood (dfe_ml)

MKtest.dfe_ml fits a distribution of fitness effects (DFE) to the SFS of synonymous and nonsynonymous sites and estimates alpha from the substitutions it predicts. It is the GRAPES model (Galtier 2016) in pure Julia:

  • the nonsynonymous SFS is the DFE-weighted Poisson random field sojourn of mutations with selection coefficient S = 4 Ne s;
  • demography and other distortions of the SFS are absorbed by one nuisance factor r_j per frequency bin, shared by both classes, and profiled out with theta;
  • ancestral misorientation is a free rate, misorient;
  • alpha is the share of observed Dn not explained by mutations with S <= nearly_neutral (default 5).
using MKtest
sfs, div, _ = MKtest.parse_sfs("data/MKdata_tgp_may2023.txt"; sample_size = 661)
s20 = MKtest.project(sfs, 20)                 # 20 individuals = 40 chromosomes

r = MKtest.dfe_ml(s20, div, MKtest.GammaZero())

The result: DFEResult

dfe_ml returns a DFEResult: a set of tables (DataFrames) with the same columns whatever the model. Every row carries fit (one id per fitted model x dataset x settings), dataset and model, so results of different models or calls stack with vcat and join on fit.

  • Intervals are (lo, hi) tuples: r.inference.alpha_ci[1]. The CI is GRAPES' likelihood interval (alpha_ci_threshold = 1.92, half the chi-square(1) 95% quantile); alpha_ci_threshold = 0 turns it off (NaN bounds).
  • at_bound marks a free parameter that ended on its bound: its value is the bound, not an estimate (a warning is also printed).
  • divergence splits the expected Dn by S class, as GRAPES' prop_subst_*: strongly deleterious (S <= -5), weakly deleterious, weakly advantageous (0 < S <= 5) and strongly advantageous. alpha = Dn_sadv / Dn_total, where Dn_total is the observed Dn (the default SaturatedDivergence).
  • Two readings of alpha. alpha_div uses the observed Dn as denominator (it equals alpha by default); alpha_dfe uses the Dn the fitted DFE predicts (Dn_pred). They agree when the DFE explains the observed divergence.

Accessors:

Saving: MKtest.write_dfe_result("out/tgp", r) writes one CSV per table (out/tgp_inference.csv, _params.csv, ...; intervals as _low / _high) and MKtest.read_dfe_result("out/tgp") reads them back. JLD2.save("r.jld2", "result", r) keeps everything in one file.

Parameter names

Every parameter is named <component>_<quantity>, so the same quantity has the same name in every model:

  • components: del (S < 0), ben (S > 0), neu (a point mass at S = 0), lethal, or a family prefix (beta_, fgm_, spike_);
  • quantities: prop (mixture weight), mean (mean |S| of the component, a positive number), shape, sigma, shift.

Fixing and bounding parameters

MKtest.dfe_ml(s20, div, MKtest.GammaExpo(); fixed = (ben_prop = 0.01,),
              bounds = (ben_mean = (1e-3, 100.0),))

Names are those of the model plus misorient and the kernel's parameter; an unknown name is an error.

ben_prop is bounded at 0.1 by default, GRAPES' cap (its MAX_ORIENTATION_ERROR reused as a mixture weight), kept so results compare with the GRAPES binary. When the cap binds (at_bound), widen it for a scientific fit: bounds = (ben_prop = (1e-6, 0.99),). On human data the uncapped beneficial class has a mean S well below 1: an effectively neutral class rather than adaptive mutations, which is why GammaExpo is best reported next to NeuGamma.

  • bounds and fixed reach each model restricted to the parameters it has.
  • A model is nested in another when its free parameters are a strict subset of the other's (GammaZero in GammaExpo and in NeuGamma; ExpoZero in GammaZero).
  • Fits are compared only on the same data and the same likelihood function: models fitted with different integrators, kernels or projections are in different groups.
  • Both tables are sorted by log-likelihood; pick the best model by argmin(aic), not row
  • MKtest.dfe_model_comparison(r) compares fits already in a DFEResult (e.g. vcat(r1, r2)).

GammaExpo / GammaGamma alpha is weakly identified. Small numbers of strong beneficial mutations and large numbers of weak ones predict nearly the same SFS, so alpha can move along a ridge at almost constant likelihood. Report it with its log-likelihood and the comparison against GammaZero, not alone.

Integrators and the GRAPES binary

The default ExactSojourn() computes the expected SFS in closed form, to about 1e-16. GRAPES integrates with Romberg over [1e-4, 1 - 1e-4], which loses mass from the rare bins (bin 1 is low by 0.19% at 20 chromosomes and 6.4% at 1322). To compare with the binary, use integrator = MKtest.RombergIntegrator():

MKtest.dfe_ml(s20, div, MKtest.GammaZero(); integrator = MKtest.RombergIntegrator())
# loglik -321.809, alpha 0.1162 (0.1052, 0.1272); the GRAPES binary: -321.809, 0.1163

MKtest.grapes(sfs, div, "GammaZero"; n = 20) runs the binary itself (installed through CondaPkg) and returns its output table, with GRAPES' column names.

On the 1000 Genomes SFS at 10 and 20 individuals, dfe_ml under Romberg equals the binary's log-likelihood at the binary's own parameters for every model tested. The fits match for GammaZero. For GammaExpo and GammaGamma, dfe_ml reaches an equal or higher likelihood, at a different point of the ridge, so alpha differs.

Reusing tables

The expected-SFS tables depend on the sample size and on the integrator, grid, dominance and expectation, not on the data. Pass one cache to reuse them across calls (safe across threads):

cache = MKtest.DFECache()
res = vcat((MKtest.dfe_ml(s, d, MKtest.GammaZero(); cache = cache) for (s, d) in zip(sfs_list, div_list))...)
